# marble-media（公開）

ビー玉ぶつりラボの、**Founder が承認した動画だけ**を置く公開用の置き場所です。GitHub Pages で配信し、Instagram と TikTok の投稿の仕組みが、ここから動画を取りに来ます。
本体（非公開）：shun0524/marble-physics-lab の tools/publish/。承認されていない動画や、秘密の情報は置きません。

- `YYYY-MM-DD/`：その日に投稿する動画
- `test/`：初回設定の確認用（プロフィール画像から作った3秒の動画と画像）
- `tiktok-callback.html`：TikTok の認可の戻り先（コードを画面に表示するだけ。外部に送信しない）
- `terms.html`・`privacy.html`：TikTok の開発者アプリ用の利用規約とプライバシー
