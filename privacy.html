プライバシー（ビー玉ぶつりラボ 投稿ツール）

このツールは、運営者自身のアカウントに動画を投稿するためだけに使います。ほかの人の情報は集めません。

連携のためのトークンは、運営者の GitHub の秘密の保管場所（Secrets）にだけ保存し、ほかの目的には使いません。連携はいつでも各サービスの設定から解除できます。

Privacy: This tool only posts the operator's own videos to the operator's own accounts. It does not collect information about other people. Access tokens are stored only in the operator's private GitHub Secrets and are not used for any other purpose.
